解決什麼問題

接手者需要知道哪些限制是刻意的（例如沒有 npm），避免「順手現代化」破壞零建置的特性。

層使用為什麼
3DThree.js r180（隨附在 web/vendor）成熟、不需打包；以 importmap 載入
網頁原生 ES modules、Canvas 2D 繪製貼圖零建置；貼圖程序化產生，無版權素材
資料處理Python 3 標準庫抓取與轉換一次性執行，不需套件
本機伺服器Node 內建 http（web/server.cjs）只聽 127.0.0.1、擋 ../ 路徑
測試Node assert（.mjs）＋ Python unittest純資料模組可在 Node 直接測
部署任何靜態主機（如 GitHub Pages）web/ 內全為相對路徑

關鍵技術手法

手法用在哪白話
幾何合併建築、店面、招牌同材質的東西併成一大塊，一次畫完
實例化繪製行人、車輛、樹、花同一個模型畫幾千次只算一次
頂點著色器動畫行人擺臂擺腿動作在顯示卡上算，不佔主程式
室內貼圖（interior mapping）店內縱深在玻璃上用視線算出虛擬房間
靜態光照圖夜間地面與低層牆面把燈光預先畫成一張圖
