檔案地圖

每個檔案負責什麼。標「純資料」的模組不依賴瀏覽器，可在 Node 測試。

解決什麼問題

約 30 個模組、單檔多在 300 行內。找「這個東西在哪改」時先看本表，再看 想加 X 改哪。

scripts/fetch_osm.py資料Overpass 抓建築／道路與店家點位

web/app.js入口組場景、鳥瞰／漫遊切換、輸入、時間、小地圖、明信片
web/city.js建築建築網格、窗格貼圖、地標立面、地面與道路
web/streetscape.js店面店面分節、門框貼圖、招牌圖集；串接店內
web/shop-layout.js店面店面分節（純資料）
web/shop-types.js店內OSM 分類 → 業態、就近招牌、同業態合併（純資料）

web/shop-paint-kit.js店內公尺座標畫筆、人台／桌椅／層架等共用輪廓

慣例
新功能先寫「純資料」模組（位置、分類、規則）加 Node 測試，再寫繪製模組。這樣規則能測，繪製只負責畫。
