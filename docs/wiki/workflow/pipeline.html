端到端流程

從公開地圖資料到使用者畫面的五步。只有第一步需要網路與人工。

人工（維護者／使用者操作） 自動腳本 LLM（本專案未使用） 檔案 / 儲存 外部 API
只有 ① 需要網路與人工；②③ 的結果已放在專案內，④⑤ 在使用者瀏覽器內完成，沒有後端服務。

解決什麼問題

3D 城市通常依賴大型模型檔或伺服器。本專案把「資料轉換」與「畫面生成」分開：轉換一次、結果放進專案；畫面每次在瀏覽器裡現做。

每一步做什麼

步驟誰做何時詳細
① 取得人工 觸發 外部想更新地圖時重建地圖資料
② 轉換自動緊接 ①重建地圖資料
③ 靜態檔儲存隨專案提交資料格式
④ 組場景自動每次開網頁網頁載入、店面、日夜
⑤ 漫遊使用者—功能一覽

考慮了哪些情況

情境怎麼應對
Overpass API 忙碌或失敗依序嘗試 4 個公開節點
只想補缺的檔案fetch_osm.py --skip-existing
離線開發② 只讀本機 work/ 的原始資料，不需網路
為什麼這樣設計
把可重複、耗時的轉換放在 Python 腳本，網頁只負責呈現：資料出錯時看 JSON 就能定位，不必在瀏覽器裡除錯。
