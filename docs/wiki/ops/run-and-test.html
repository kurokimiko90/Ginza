啟動

node web/server.cjs              # http://127.0.0.1:8770/
PORT=8780 node web/server.cjs    # 換埠

什麼時候用：每次開發。為什麼：瀏覽器不允許 file:// 載入模組與 JSON。需要 Node（驗證環境 v25）與支援 WebGL 2 的瀏覽器。
